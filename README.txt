GatherGlow 0.1.20 for World of Warcraft: Forever 1.60.1

Install
1. Close WoW: Forever.
2. Extract the GatherGlow folder to World of Warcraft\_forever_\Interface\AddOns.
   GatherGlow_Camelot.toc should be directly inside the GatherGlow folder.
3. Start WoW: Forever and make sure GatherGlow is enabled in the AddOns list.

On or off
Open Esc > Options > AddOns > GatherGlow and use Enable GatherGlow.
It starts enabled and remembers your choice. Turn it off before uninstalling
so it can restore any Interact Key settings it changed.

In the world
A glowing marker shows the nearby gathering target WoW picks for your Interact
Key. A green leaf means herb, an icy-blue crystal means ore, and an amber hide
means ready to skin.
GatherGlow uses WoW's widest Interact Key angle, so the marker can appear on
targets off to the side. It requests a 60-yard range, and WoW determines
which nearby target is actually available.

Herbs chime and ore plays an anvil strike once per encounter.
The same node can chime again after it has been out of view for 25 seconds.
During combat, the addon waits and only chimes if WoW still detects the node
as the current gathering target after the fight. Skinning is silent.

The marker flashes once and holds steady when the target comes within Interact
Key range. It resumes pulsing if you move out of reach.

On the minimap
Outlined blue fish mark 337 known fishing spots across 17 Azeroth zones, including
fishable wreckage and debris. Check the water for an active pool when you get
there. The included locations do not cover Forever's new zones.
